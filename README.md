# DataDNA Challenge Credit Risk Analytics September 2025

This repository contains the code for the DataDNA Challenge on Credit
Risk Analytics held in September 2025. The project focuses on developing
predictive models to assess credit risk using various machine learning
techniques.

[Building a Credit Risk Dashboard with Power BI and
R](https://blog.frequentist.org/posts/20250927-credit-risk-analytics/) —
a blog posts.

## Source code

1.  [Exploratory Data
    Analysis](https://blog.frequentist.org/posts/20250927-credit-risk-analytics/01_eda.html)
    ([source](01_eda.qmd)) — exploratory data analysis, data cleaning
    and preparation, some modelling and predictors selection.

2.  [Modelling Credit
    Risk](https://blog.frequentist.org/posts/20250927-credit-risk-analytics/02_modelling.html)
    ([source](02_modelling.qmd)) — model training, evaluation, and
    comparison of three algorithms: Logistic Regression, Random Forest,
    and XGBoost.

3.  [Scripts for Power
    Query](https://blog.frequentist.org/posts/20250927-credit-risk-analytics/03_power_query.html)
    ([source](03_power_query.qmd)) — a collection of scripts for data
    extraction and transformation in Power Query.

4.  [Synthetic Data For
    Simulations](https://blog.frequentist.org/posts/20250927-credit-risk-analytics/04_synthetic_data.html)
    ([source](04_synthetic_data.qmd)) — a script to generate synthetic
    data for simulations in Power BI.
